# Revisión editorial antes de publicar

- Respaldo usado: `feed.atom`.
- Se conservaron 35 publicaciones y 3 páginas del blog.
- Se copiaron 36 imágenes a la carpeta local del sitio. Sus permisos de publicación aún no están confirmados.
- Se retiraron de las páginas tres imágenes que dependían directamente de Blogger y no tenían una copia local coincidente.
- No se importaron comentarios, seguidores, perfil ni configuración personal.
- El repositorio sigue privado; este informe acompaña el borrador y no se ha publicado GitHub Pages.

## Revisiones aplicadas

1. **Reto de 21 días:** se aclaró que la entrada original contiene un circuito, no un plan progresivo de 21 días. Se identificó que la sección original llamada “vuelta a la calma” mantiene el esfuerzo.
2. **Vuelta a la calma:** se separaron las dos entradas —explicación y ejercicios— y se eliminaron promesas de eliminar lactato o prevenir lesiones. Se añadieron fuentes.
3. **Calentamiento:** se sustituyó el borrador con instrucciones de redacción y el dato del 50% por una guía gradual con ejemplos adaptables y fuentes.
4. **Temario:** quedó identificado como un archivo de ideas, no como una guía ni recomendación.
5. **Títulos:** se normalizaron errores ortográficos visibles; el respaldo original no se modificó.
6. **Nutrición y aminoácidos:** se reescribieron las entradas marcadas con explicaciones generales, límites claros y fuentes oficiales. Se quitaron afirmaciones absolutas sobre necesidades, daño por exceso o beneficios de suplementos.
7. **Privacidad y contacto:** la política ahora describe el sitio estático previsto para GitHub Pages y no afirma que AdSense, Analytics o un formulario ya estén instalados. La página de contacto ya no promete un formulario inexistente.
8. **Autoría:** la sección “Acerca de” no atribuye credenciales ni revisión profesional no confirmadas.

## Confirmaciones necesarias antes de hacer público el repositorio

1. **Derechos de las imágenes:** confirma que tienes permiso para publicar las 36 imágenes, o indica cuáles son tuyas y cuáles debemos reemplazar. Las imágenes adjuntas no prueban por sí solas que exista licencia para reutilizarlas.
2. **Texto alternativo:** las descripciones de varias imágenes todavía requieren revisión manual para que representen correctamente cada ilustración.
3. **Correo de contacto:** se conservó el correo público del Blogger (`contacto@elmundodelfitness93.com`). Confirma que siga activo y que quieras dejarlo visible en el sitio.
4. **Autoría:** no se inventó nombre, experiencia ni credencial. Puedes mantener la presentación actual o facilitar la biografía real que quieras mostrar.
5. **Servicios futuros:** si luego agregas AdSense, Analytics, formularios u otras herramientas, habrá que actualizar la política y configurar los avisos que correspondan antes de activarlos.
